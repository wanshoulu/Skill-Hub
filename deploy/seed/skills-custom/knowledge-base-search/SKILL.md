## 适用场景与触发条件

当用户提出查询问题，并期望从已加载的参考资料或用户提供的文档中获取答案时加载本 Skill。

典型触发语句：
- "帮我查一下公司差旅制度"
- "知识库里有没有关于报销流程的说明"
- "搜索一下住宿标准是多少"

**不适用场景：**
- 用户要求联网搜索或查询外部实时信息（本 Skill 仅检索已有资料）
- 知识库中不存在相关资料，且用户未提供新文档
- 用户要求对检索结果做评价、预测或超出原文的推断

## 输入与前置条件

- **必需**：用户的查询问题或关键词
- **必需**：可检索的资料源，包括：
  - 已加载的参考资料（如 `references/` 下的文档）
  - 用户在当前对话中提供的文档或文本
- **工具**：文本读取与关键词匹配能力；若资料为二进制格式（.docx / .pdf），需先确认是否有可用解析工具，无则请用户转为纯文本
- **权限**：仅需读取已有资料，无需外部系统访问

## 执行流程

1. **解析查询**：从用户问题中提取核心关键词与检索意图（如"住宿标准""报销流程"）。
2. **确定检索范围**：列出当前可检索的资料源。若无任何资料源，进入异常处理。
3. **执行检索**：在资料源中按关键词及同义表述进行匹配，定位相关段落。
4. **提取原文片段**：截取与问题直接相关的原文内容，保持原样，不改写、不归纳。
5. **标注出处**：为每个片段标明来源（文件名或资料名称，如有章节/条目位置一并标注）。
6. **输出结果**：按下方格式返回。

输出格式：

```
【检索结果】
- 片段：<原文内容>
  出处：<文件名 / 资料名称>（<章节或条目位置，如有>）
- 片段：<原文内容>
  出处：<文件名 / 资料名称>（<章节或条目位置，如有>）

【未命中说明】（仅当无匹配时输出）
未在已加载资料中找到与"<查询关键词>"相关的内容。
```

## 完成标准

满足以下全部条件时，视为本次检索任务完成：

1. 已明确列出本次实际检索的资料源范围。
2. 对每个命中项，均返回了与问题直接相关的原文片段，且片段保持原样、未改写或归纳。
3. 每个片段均标注了可追溯的出处（文件名或资料名称，如有章节/条目位置一并标注）。
4. 若存在未命中的查询意图，已明确说明"未找到相关内容"，而非编造答案。
5. 输出结构符合上方"输出格式"要求。

## 异常处理与安全边界

**异常处理：**
- **无可用资料源**：不执行检索，明确告知用户当前没有可检索的资料，并请其提供文档或文本。
- **二进制格式无法解析**：说明缺少可用解析工具，请用户转为纯文本后再检索。
- **关键词无匹配**：返回"未命中说明"，不臆测、不补全答案。
- **查询意图模糊**：向用户澄清具体检索目标后再执行，不擅自扩大检索范围。

**安全边界：**
- 仅检索并返回已有资料中的原文，不联网、不访问外部系统。
- 不编造资料中不存在的内容，不将推断、评价或预测作为检索结果输出。
- 不修改、删除或覆盖原始资料，仅做只读检索。
- 涉及敏感资料时，仅返回与用户查询直接相关的片段，不主动扩散无关内容。
- 若用户要求超出原文的推断或评价，说明本 Skill 不适用并拒绝该部分请求。
